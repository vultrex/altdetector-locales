# Alt Detector Locales

This repository contains the official community-driven translation files for **Alt Detector**. By keeping our localization open, we allow the community to help make the bot accessible and safe for Discord servers globally, regardless of their language.

---

## 🌎 Supported Languages

Our core translation files are located in `locales/i18n/`. We currently use **English (US)** as our master template.

* **Primary Source:** `locales/i18n/en.ts`
* **Contribute:** We are looking for translations in French, German, Polish, Italiano and more!

---

## 🚀 How to Help

We love community contributions! To add a new language or improve an existing one:

1. Navigate to the `locales/i18n/` directory.
2. Follow the instructions in our [**CONTRIBUTING.md**](./CONTRIBUTING.md) to ensure the TypeScript syntax and placeholders (like `{user}` or `{guild}`) remain intact.
3. Submit a **Pull Request** with your new or updated `.ts` file.

Once a Pull Request is merged, the new language will be reviewed and integrated into the bot in a future update.
